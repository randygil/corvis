# Apóyanos

Corvis es software libre, publicado bajo la licencia MIT. La forma más útil de apoyar el proyecto es usarlo y contar qué falta:

- **Reporta errores** con un caso mínimo que los reproduzca.
- **Propón mejoras** abriendo un issue antes de un cambio grande.
- **Contribuye código o documentación.** Antes de enviar un cambio, ejecuta `cargo test --workspace`.

Todo ocurre en el [repositorio del proyecto](https://github.com/randygil/corvis). No hay, por ahora, un programa de patrocinio.
