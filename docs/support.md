# Support us

Corvis is free software, released under the MIT license. The most useful way to support the project is to use it and tell us what is missing:

- **Report bugs** with a minimal case that reproduces them.
- **Suggest improvements** by opening an issue before a large change.
- **Contribute code or documentation.** Before sending a change, run `cargo test --workspace`.

Everything happens in the [project repository](https://github.com/randygil/corvis). There is no sponsorship program for now.
