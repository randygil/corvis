# MikroORM

MikroORM es un ORM de Node.js y no tiene integración con Corvis.

## Alternativa

Usa [corvis-orm](/data/corvis-orm) para modelos, relaciones y transacciones con PostgreSQL o SQLite, o registra el cliente de base de datos que prefieras como provider (ver [Visión general](/data/overview)).
