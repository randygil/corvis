# Transports

Corvis does not include a Model Context Protocol (MCP) server: there is no module, no tool, resource or prompt decorators, and no MCP transports.

There are no MCP transports (stdio, streaming HTTP). Corvis does serve [Server-Sent Events](/http/server-sent-events) and [WebSockets](/websockets/gateways), but it does not implement the protocol.
