# Transportes

Corvis no incluye un servidor del Model Context Protocol (MCP): no hay módulo, decoradores de herramientas, recursos o prompts, ni transportes MCP.

No hay transportes MCP (stdio, HTTP con streaming). Corvis sí sirve [Server-Sent Events](/es/http/server-sent-events) y [WebSockets](/es/websockets/gateways), pero no implementa el protocolo.
