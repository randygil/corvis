# Internacionalización

Corvis no tiene un módulo de internacionalización: no hay carga de catálogos de traducciones, resolución del idioma por petición ni un servicio de traducción inyectable.

## Alternativa

- Los mensajes de error de `corvis::z` se pueden mostrar en español con el locale incluido: `z::configure(|c| c.locale_error = Some(z::locales::es()))`. Es una configuración global del proceso (ver [Validación](/es/application/validation)).
- Para leer el idioma preferido del cliente, toma la cabecera `Accept-Language` con `#[headers("accept-language")] lang: Option<String>` en el handler, o crea un parámetro propio con `FromContext` (ver [Decoradores personalizados](/es/custom-decorators)).
- Para los textos de tu aplicación, carga tus catálogos en un provider propio (por ejemplo con `Provider::use_value`) o usa un crate de i18n de Rust.
