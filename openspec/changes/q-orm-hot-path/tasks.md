# Tasks

Start after `q-orm-correctness` is merged into `dev`. Shared Cargo target directory only (never a target directory per
task). Postgres tests need the local server (`corvis-pg`, `127.0.0.1:55432`) and run with `CORVIS_ORM_PG_REQUIRED=1`.
Timing rule for every test: assert results, statement counts, decoded-row counts and accepted sockets; wait for conditions
with a deadline that only fails the test; never `sleep` to synchronize; never compare durations between runs. The benchmark
and test servers bind to `127.0.0.1` only. Results, their order, counts and errors must not change.
