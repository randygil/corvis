# Proposal

Implements the issue filed from `quality/q-openapi-schemas-for-rust-types-and-versions.issue.md` (epic
[#187](https://github.com/randygil/corvis/issues/187), code quality audit). Source: the engineering-quality review of
`corvis-swagger`, `corvis-swagger-macros`, `corvis-cli` and the workspace, read against `dev` at `d46758a`. This change
covers what the OpenAPI document says (findings M1, M2, M3, S2 and S3 of the review). The serving hot path, the macro
option checks and the API surface (S1, S4, S5 and the nice-to-have items) are
`q-openapi-serving-and-api-hygiene`, which lands after this one. Both land after
`q-workspace-ci-gates-and-lint-ratchet`.

## Why

The generator reproduces the original library's document, key order included, and the parity check compares the
documents of the port apps byte for byte. That part works. What does not is the part with no counterpart in the
original: Rust types.

- `Page<User>` and `Page<Post>` both become the component `Page` (`crates/corvis-swagger-macros/src/derive.rs:153`
  uses a short name that drops generic arguments, `crates/corvis/src/openapi.rs:69-71`); the second overwrites the
  first with only a warning (`crates/corvis-swagger/src/schema_factory.rs:532-539`), so every `$ref` to `Page` points
  to one of them.
- `DateTime<Utc>`, `NaiveDate`, `Uuid`, `Box<T>`, `HashSet<T>` and every enum without extra attributes become empty
  object components (`crates/corvis-swagger/src/types.rs:117-163` implements `SwaggerType` for primitives, `Vec`, maps,
  `Option` and `SystemTime` only; the fallback is `types::opaque_marker`, `lib.rs:98-101`). The user cannot fix it with
  `impl SwaggerType for chrono::DateTime` (orphan rule), and handler parameters use a different table
  (`types.rs:216-244`) that does know `DateTime` and `Uuid`.
- An `Option<T>` field only gets `required: false` (`schema_factory.rs:167-169`), while serde writes `null` for `None`;
  `#[serde(flatten)]`, `skip_serializing_if` and `default` are ignored (`derive.rs:179`).
- For a float `#[is_positive]`, the derive writes `exclusiveMinimum: 0` (`constraints.rs:181,183`), which is OpenAPI
  3.1 syntax, into a document that declares `3.0.0` (`explorer.rs:155`, `document.rs:135`).

The review also listed three forms that are invalid for the declared version but come from the original: a `nullable`
response as `oneOf` with `{ type: "null" }` (`explorer.rs:461`), the `search` key of a route on every method
(`explorer.rs:312`), and references the zod cleanup does not rename under `items` (`zod.rs:352-361`) or in `options` /
`search` operations (`zod.rs:594`). The original's source (`@nestjs/swagger` 11.4.6 and `nestjs-zod` 5.5.0, read in the
port apps' `node_modules`) produces exactly the same, so by default they stay, and this change records them in a fixture
generated by the original and offers a strict cleanup that makes the document valid for its version.

## What Changes

- **Recorded fixture of document forms.** `crates/corvis-swagger/tests/fixtures/document_forms/`: a script that runs the
  original generator and its zod integration on an app with nullable responses, a route on every method, a renamed zod
  DTO under `items`, a 3.1 document with `nullable`, and the cats app of `tests/swagger_app.rs`; the Rust test builds the
  same app and compares the whole document byte for byte. The golden values of `swagger_app.rs` (pasted by hand from a
  run that left no script) become regenerable.
- **One component per generic instantiation.** `Page<User>` is `Page_User`; names of non-generic types do not change.
  The derive bounds each type parameter by `ApiSchema` unless `#[api_schema(bound = "...")]` says otherwise.
- **Rust scalar types described.** One table of Rust scalar types (name, constructor, format) used by `SwaggerType`
  implementations and by handler parameters; `SwaggerType` for `Box`, `Arc`, `Rc`, sets, `VecDeque`, arrays and
  `NonZero*`; features `chrono` (default), `uuid` (default) and `time`; `SwaggerDocumentOptions::with_type::<T>(schema)`
  for any other foreign type; a warning, once per type and document, when a type falls back to an empty object.
- **Unit enums.** `#[derive(ApiSchema)]` on an enum with unit variants gives an inline `enum` with the names serde
  writes.
- **What serde writes.** `Option<T>` without `skip_serializing_if` is optional and nullable; `default` and
  `skip_serializing_if` make a field optional; `flatten` splices the inner type's properties; `rename(serialize = ..)` is
  read.
- **Corvis keywords in the declared version.** Exclusive bounds and nullability that Corvis adds are written as
  `minimum` + `exclusiveMinimum: true` / `nullable: true` in 3.0 and as numbers / type arrays in 3.1.
- **Strict cleanup (opt-in).** `try_cleanup_open_api_doc(doc, CleanupOptions { strict: true, .. })` renames references
  everywhere, rewrites the inherited forms for the declared version, drops `search` operations and fails on a dangling
  `$ref`. A test validates strict documents against the official OpenAPI 3.0 and 3.1 schemas.
- **Homonyms.** The duplicate warning names both Rust types and how to rename one; the behavior stays the original's.

## Capabilities

### New Capabilities

- `openapi/document`: document-level rules: component names of generic types, foreign types per document, Corvis
  keywords in the declared version, inherited forms kept by default, strict cleanup, the recorded fixture, the homonym
  warning, leftover zod markers reported when served.

### Modified Capabilities

- `openapi/api-schema`: the keyword table changes for float exclusive bounds (version form); added requirements for
  scalar types, unit enums, optional fields and flattened fields.

## Impact

- New: `crates/corvis-swagger/tests/fixtures/document_forms/{package.json,package-lock.json,app.ts,generate.mjs,document_forms.json}`,
  `crates/corvis-swagger/tests/document_forms.rs`, `crates/corvis-swagger/tests/rust_types.rs`,
  `crates/corvis-swagger/tests/openapi_schema.rs`, `crates/corvis-swagger/tests/fixtures/oas/{3.0,3.1}.json`,
  `crates/corvis-swagger/src/version.rs` (the finishing pass and strict normalization).
- Edited: `crates/corvis-swagger/src/{types,lib,explorer,schema_factory,zod,document,swagger_module,scalar}.rs`,
  `crates/corvis-swagger-macros/src/{derive,constraints}.rs`, `crates/corvis-swagger/Cargo.toml` (features, optional
  `chrono` / `uuid` / `time`, dev-dependency `jsonschema`), `crates/corvis-swagger/tests/api_schema_constraints.rs`,
  `crates/corvis/src/openapi.rs` (`on_unimplemented` note on `ApiSchema`), `docs/openapi/types-and-parameters.md`,
  `docs/openapi/other-features.md` and their Spanish pages.
- Public API: `SwaggerDocumentOptions::with_type`; `CleanupOptions` and `try_cleanup_open_api_doc(doc, CleanupOptions)`
  (today `(doc, OpenApiVersion)` returning `Result<_, String>`; it now returns `Result<_, SwaggerError>`, the error type
  `q-openapi-serving-and-api-hygiene` completes); `#[api_schema(bound = "...")]`; `#[derive(ApiSchema)]` accepted on
  unit enums; new `SwaggerType` impls; features `chrono`, `uuid`, `time`. Changed now, before 1.0.
- Documents that change: only those of `#[derive(ApiSchema)]` DTOs with generics, scalar types, enums, `Option`, serde
  attributes or float exclusive bounds, and of handler parameters typed `Uuid`, `NaiveDate`, `NaiveTime` (a `format`
  added). Documents built only from zod DTOs, `String` parameters and decorators, which is what the port apps use, do
  not change; the parity check decides (task 9.4).
- Dependencies: `chrono` and `uuid` (already in `Cargo.lock`, now optional dependencies of `corvis-swagger`), `time`
  (already in `Cargo.lock`), dev-dependency `jsonschema` (new; checked with `cargo deny` in task 7.1).

## Out of scope

- Integers as `type: integer`: the fixture of the original plugin records `type: number` for TypeScript `number`, and
  that parity is kept.
- Translating `#[matches]` regular expressions to ECMA-262: decided and documented by the archived
  `e13-apischema-ignores-validation-constraints` (Decision 5).
- Making the zod cleanup automatic: the original requires the explicit call too; a served document that still carries
  zod markers is reported instead (design.md Decision 9).
- Serving, caching, macro option checks, public module surface, startup cost: `q-openapi-serving-and-api-hygiene`.
