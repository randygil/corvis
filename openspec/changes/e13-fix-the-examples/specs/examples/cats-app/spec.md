# Spec Delta

## ADDED Requirements

### Requirement: No default JWT secret
The `cats-app` example SHALL NOT sign or verify tokens with a built-in secret. When `JWT_SECRET` is missing, empty or
only whitespace (in the environment and in `.env`), application creation MUST fail with an error that names
`JWT_SECRET`. `examples/cats-app/.env.example` MUST NOT contain a value that works as a secret.

#### Scenario: Started without JWT_SECRET
- **WHEN** `cats_app::create_app()` runs with no `JWT_SECRET` in the environment and no `.env` in the working directory
- **THEN** it returns an error whose text contains `JWT_SECRET`

#### Scenario: Empty JWT_SECRET
- **WHEN** `JWT_SECRET` is set to an empty string
- **THEN** application creation fails with the same error

#### Scenario: Copying the example environment file
- **WHEN** a user copies `.env.example` to `.env` without editing it
- **THEN** the application refuses to start and the error says `JWT_SECRET` is required

### Requirement: The example publishes an OpenAPI document
The `cats-app` example SHALL mount the OpenAPI document produced by `corvis-swagger` (Swagger UI at `/docs`, JSON at
`/docs-json`), describe its request DTOs and the `Cat` entity with `#[derive(ApiSchema)]`, and declare bearer
authentication. The document MUST be generated by the same `create_app()` the binary uses.

#### Scenario: Document lists the cats routes
- **WHEN** a test requests `/docs-json` from the application returned by `create_app()`
- **THEN** the response is `200` and `paths` contains the versioned cats routes (for example `/api/v1/cats` and
  `/api/v1/cats/{id}`) with the `cats` tag

#### Scenario: DTO and entity schemas come from ApiSchema
- **WHEN** the same document is inspected
- **THEN** `components.schemas` contains `CreateCatDto` with the properties `name`, `age` and `breed`, and `Cat` with
  `ownerId` (the serde `camelCase` name), and the login body references `SignInDto`

#### Scenario: Bearer auth declared
- **WHEN** the same document is inspected
- **THEN** `components.securitySchemes` contains a bearer scheme and the protected cats routes reference it
