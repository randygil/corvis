# cli/new Specification

## Purpose
What `corvis new` generates: a project that builds, tests and runs, with the defaults a new application should
start from (route posture enforced, the root route marked public).

## Requirements

### Requirement: New projects enforce route posture
The project generated by `corvis new` SHALL enable route posture in enforce mode in its `main` (by calling
`require_route_posture()` before `listen`), and every route it generates SHALL be either guarded or marked
`#[public]`, so the generated project starts as generated and `corvis posture` exits with status 0 for it.

#### Scenario: Generated project starts
- **WHEN** a project is created with `corvis new my-app` and run without changes
- **THEN** it starts and serves `GET /` as before

#### Scenario: Generated project passes the report
- **WHEN** `corvis posture` runs in a project created with `corvis new` and not modified
- **THEN** it lists `GET /` (`AppController::get_hello`) as public and exits with status 0

#### Scenario: Route added without a guard
- **WHEN** a route with no guard and no `#[public]` is added to the generated `AppController` and the project is run
- **THEN** the application refuses to start with the route posture error that names the new route
