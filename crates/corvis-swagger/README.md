# corvis-swagger

OpenAPI module for the [Corvis](https://corvis.randygil.com) backend framework: an OpenAPI 3 document generator,
`Api*` decorators, `#[derive(ApiSchema)]`, zod DTO support, Swagger UI and the Scalar API reference.

It builds on [`corvis`](https://crates.io/crates/corvis); add both to your project:

```toml
[dependencies]
corvis = "0.1"
corvis-swagger = "0.1"
```

- Documentation: <https://corvis.randygil.com>
- Repository: <https://github.com/randygil/corvis>
