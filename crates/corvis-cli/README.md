# corvis-cli

Command-line tool (`corvis`) of the [Corvis](https://corvis.randygil.com) backend framework. It scaffolds new
projects (`corvis new`), generates modules, controllers, services, guards, interceptors, pipes, filters, middleware,
gateways and resources (`corvis generate`), and wraps `cargo run` and `cargo build` (`corvis start`,
`corvis build`).

```sh
cargo install corvis-cli
corvis --help
```

- Documentation: <https://corvis.randygil.com>
- Repository: <https://github.com/randygil/corvis>
